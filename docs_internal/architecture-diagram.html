CopySpeak Architecture

v0.1.13 — Tauri 2 (Rust) + Svelte 5 clipboard-to-speech orchestrator for Windows

Stack

  • • Frontend: Svelte 5 + TS + Vite, Tailwind v4, shadcn-svelte, svelte-i18n
  • • Backend: Rust (Tauri 2), rodio audio, tokio subprocess, reqwest
  • • Windows integration: Win32 clipboard listener, global shortcuts, tray, autostart
  • • Package manager: Bun · targets: Windows WebView2

Speech pipeline

  • • Triggers: double-copy (1.5s), global hotkey, tray, control server POST /speak
  • • clipboard.rs holds the double-copy state machine
  • • sanitize → optional Groq rewrite → tts/ dispatch (11 engines)
  • • audio FX → rodio playback → HUD overlay + history log

IPC surface

  • • UI → Rust: invoke (config, playback, tts synthesis, history, install, update)
  • • Rust → UI events: audio-ready, playback-stop, config-changed, synthesis-state-change, history-updated, hud, clipboard-change
  • • Control server (local HTTP): GET /health, POST /speak — used by Pi + Claude Code extensions
  • • Auto-updater pulls from GitHub Releases
